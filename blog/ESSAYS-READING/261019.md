## 投机
### 是什么？
1. 投机的前身：`Speculative Execution`
CPU总是在等 -> 在if时猜一下分支吧
对了 -> 提交寄存器
错了 -> 刷新重算
低投入，成功了便高回报，是为“投机”。
2. 回到`投机`
原本：算完第n个token再算第n+1个 -> 慢
`优化`：预填未来K步，一次前向传播同时验证
如果出错 -> `止损`：在第一个出错token开始丢弃预测
### 怎么做？
投机的`猜法`：
1. N-Gram: Prompt Lookup Decoder, Trie树(如REST)
2. 小参数模型预跑
3. Medusa(多头并行) / EAGLE
4. Tree-based Drafting 树状多分支竞标
