# 2276D
## 翻译
n点m边 无向图 点染色 红/蓝
至少一个异色邻居 求方案数
野人，只知1、2、many，不识有0
0 -> brain melt
总结：输出1/2/Many/Brain Melt
## 分析
对称性 -> 输出不可能是1
case1：孤立点 -> BM
case2：链 -> 2
case3：环 -> Many
## 解
维护度数，扫到0度点 -> BM
else：多链/长链/有环 -> M；其余2
## 算法
判环 -> 找非树边 -> 并查集？（同宗相通）
数链 -> 不能并查集啊，n开到了三十万
