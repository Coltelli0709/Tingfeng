### 练习反馈
1. 染色法和类树形的find不要混用，而且细想一下确实，如果染色了时间开销也太大了
2. 添加边的时候fa值变动的逻辑，应该是端点的根节点指向另一个端点的根节点
3. 只find根节点还不够，还要给find加上路径压缩：
``` cpp
int find(int a){
    return fa[a] == a ? a : fa[a] = find(fa[a]);
}
```

## 树状数组
基于二进制拆分 (lowbit) 的`数组隐式树`。
写起来很快啊，而且缓存友好。

### 情境
Assume: 总要`修改&查询`

能不能`折中`一点呢？

### lowbit
> 讲树状数组不讲lowbit恐怕有一点耍流氓。
1. 可以理解为树状数组只能管理2的次方数个元素？
- 不可以！树状数组可以管理`任意正整数`个元素。
2. 但是下标必须是 `1 ~ n`
