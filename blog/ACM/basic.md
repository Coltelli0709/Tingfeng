### 练习反馈
1. 染色法和类树形的find不要混用，而且细想一下确实，如果染色了时间开销也太大了
2. 添加边的时候fa值变动的逻辑，应该是端点的根节点指向另一个端点的根节点
3. 只find根节点还不够，还要给find加上路径压缩：
``` cpp
int find(int a){
    return fa[a] == a ? a : fa[a] = find(fa[a]);
}
```

## 树状数组
基于二进制拆分 (lowbit) 的`数组隐式树`。
写起来很快啊，而且缓存友好。
好吧这么说还是没什么体会，不妨情境化一点。
### 情境
Assume: 总要`修改&查询`
二者各有极端：普通数组——修改O(1)，前缀和——查询O(1)。
能不能`折中`一点呢？
树状数组应运而生！
> 又看了一眼原来就是那个有的管和有的管差的金字塔一样的数据结构呀！
### lowbit
> 讲树状数组不讲lowbit恐怕有一点耍流氓。
1. 可以理解为树状数组只能管理2的次方数个元素？
- 不可以！树状数组可以管理`任意正整数`个元素。
2. 但是下标必须是 `1 ~ n`
3. 来理解一下其中的trick吧：
——卧槽天才！
根本不用循环除2取模判断，直接位运算出最右的1，其权值就是掌管的区间长度诶！一切都刚刚好！
### 改与查
> 那修改的时候怎么确定要修改的下标呢？查询时怎么选择范围呢？一定也有tricks吧？
1. 改
`x += lowbit(x)` 可以找且仅找到所有管辖x的节点！
2. 查
树状数组前缀查询函数 query(x) 的核心逻辑是通过 x -= lowbit(x) 依次剥离最低位的二进制 1，将不相交的管辖区间和累加至总和。
