# T3
> 抽签：有放回，能否凑出目标值？

1. 我的思路：去重

2. 书本点拨：二分查找 & 分组思想
二分：略。
分组：1+1+1+1有n^4种可能，枚举两两之和，再枚举和之和，则可降到二次。

3. 思考：
i. 分组求和必有大量和值重复，还是要去重。
ii. 去重+二分后计算量可以降很多。

4. AI优化：
如果 n 较大（比如 10⁴），n² = 10⁸，可能仍偏大。此时可用哈希集合代替排序+二分，查询 O(1) 平均，但需要解决哈希冲突开销。实际竞赛中 n ≤ 1000 时 n² = 10⁶ 可以接受。
如果 n 更大，可以考虑`“折半枚举”后使用双指针`进一步降低常数。
